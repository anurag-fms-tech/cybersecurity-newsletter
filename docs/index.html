Two CVSS 9.0 Linux KSMBD RCE Flaws Disclosed on Public Mailing Lists Before Kernel Fixes

Threat: Vulnerability
Severity: 10/10

Linux’s built‑in SMB server (KSMBD) has two publicly disclosed RCE bugs, each rated 9.0 by Trend Micro’s ZDI. ZDI‑CAN‑33774 is an unauthenticated race that lets attackers craft SMB1/SMB2 packet mixes to overwrite memory. ZDI‑CAN‑33549 is an integer underflow in the SMB Direct (RDMA) path that can overrun buffers if the server offers a writable share and uses RDMA hardware or the rxe driver. No patches or CVEs exist yet; a fix for the RDMA issue is pending in the next kernel cycle, while mainline remediation may take weeks. Red Hat Enterprise Linux does not ship KSMBD by default.

Training AIs to Solve CAPTCHAs

Threat: Vulnerability
Severity: 7/10

Researchers built an adaptive CAPTCHA solver that pairs a fine‑tuned YOLOv8 detector with an open‑weight vision‑language model (VLM) routed by confidence scores. Operating solely via screenshots and OS events, it reaches ≈85 % overall accuracy across 16 classes, outperforming each component alone. The VLM’s answers become training labels, letting the detector learn new categories after one or two exposures and self‑repair. Even when a CAPTCHA operator crafts adversarial perturbations that cripple the detector, the VLM remains intact and its labels enable rapid recovery, showing that visual‑CAPTCHA defenses that assume a failing bot stays broken vastly underestimate an evolving solver’s resilience.
