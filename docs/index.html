Apple’s Verified Photography System

Threat: Vulnerability
Severity: 2/10

Apple introduced “Reference Image,” a system that cryptographically verifies iPhone‑taken photos—new models only—without linking them to a specific device or photographer. It can also confirm multiple images originated from the same sensor. Unlike other solutions that require a photographer’s credentials, Apple’s service signs images via its signing service after validation through Privacy‑Centric Computation (PCC), keeping the photo data private even from Apple. A revocation service maintains sensor‑photo mappings for validity checks, but never accesses the image content. This aims to protect anonymity for photographers, especially those in conflict zones, while still proving authenticity.
