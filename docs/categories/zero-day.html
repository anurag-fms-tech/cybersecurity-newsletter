Claude Model Builds Exploits Across Major Browsers & OSes

Severity: 10/10

Anthropic’s unreleased Claude model discovered and chained five critical vulnerabilities across Chrome, Safari, Android, Windows and Linux, creating near‑automatic exploits—one‑click RCE on macOS Chrome, data theft from a locked Android phone, zero‑click root RCE on Linux servers, and a Windows crash. All flaws (62 reported to Google, CVE‑assigned) were patched after Anthropic’s disclosure, highlighting frontier AI’s growing ability to craft multi‑step attacks with minimal human input.
