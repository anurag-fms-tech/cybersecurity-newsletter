AI Is Learning to Write Genetic Code

Severity: 3/10

Researchers used AI models to design complete genomes for new bacteriophages targeting E. coli. From an existing ΦX174 template, the models produced ~700,000 designs; 285 were selected for synthesis. When inserted into E. coli, 16 cultures yielded viable phages, some outperforming the natural ΦX174. The breakthrough shows AI’s power to create functional viruses—raising both therapeutic promise and biosecurity concerns.
