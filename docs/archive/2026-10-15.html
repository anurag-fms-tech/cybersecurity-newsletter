Orphaned VBA Projects Inside DWG Files, (Wed, Oct 14th)

Threat: Vulnerability
Severity: 8/10

A researcher detailed how VBA code can hide inside AutoCAD DWG files as an embedded OLE object. By reading a 32‑bit pointer at offset 0x24, a 16‑byte header reveals the OLE payload’s length, allowing extraction with a Python script (autocad.py) and cut‑bytes.py, then analysis via oledump.py. Recently, two DWG samples broke this rule: the pointer was zero, yet a brute‑force search uncovered VBA‑laden OLE files, highlighting a new evasion vector.
