Threat: Vulnerability
Severity: 10/10

A use‑after‑free bug in Ghostscript (CVE‑2026‑125396) let a crafted PDF/PostScript/EPS file bypass the –dSAFER sandbox and execute commands on the server. CyberPower PowerPanel Exploited to Run Malicious Code on Domain Controller

Threat: Vulnerability
Severity: 10/10

A Symantec report shows attackers abusing CyberPower PowerPanel Business (PBB) to execute malicious scripts on a Windows domain controller. By uploading scripts through the PBB web console, they leveraged the software’s “run‑as‑SYSTEM” feature to deploy an antivirus killer, steal the Active Directory database, and install a persistent DLL‑sideloaded implant.
