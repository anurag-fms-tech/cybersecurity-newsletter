Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely

Threat: Vulnerability
Severity: 10/10

A critical vulnerability (CVE‑2026‑119618) in Apache HTTP Server’s HTTP/2 module, mod_http2, allows unauthenticated remote code execution on servers with HTTP/2 enabled. It impacts versions 2.4.55‑2.4.70 (and mod_h2 2.0.8‑2.0.42) and is patched in 2.4.71 (released yesterday). Red Hat rates it “Important” for RHEL 9/10 and notes a reliable exploit exists, though no wild attacks have been reported. Administrators should verify HTTP/2 settings and upgrade immediately.

Severity: 5/10

The method showcases both the power and privacy risks of combining acoustic analysis with open air‑traffic data.
