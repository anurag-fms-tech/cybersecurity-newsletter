KREMLIN Banking Malware Hijacks Chrome and Edge to Steal Credentials and Session Tokens

Threat: Malware
Severity: 9/10

Researchers uncovered a Brazilian banking malware suite called KREMLIN (tracked as REF9334) active since May 2025. It lures victims with fake bank emails, then runs a JavaScript loader that evades sandboxes, installs a Chrome/Edge extension, and deploys a C++ installer that sideloads a fake SentinelAgentCore.dll. C2 URLs are stored in Ethereum smart contracts, enabling blockchain‑based updates and persistence via scheduled tasks.

MacOS 27 - First Boot, (Tue, Sep 15th)

Threat: Vulnerability
Severity: 1/10

Four TCP connections were opened, using the same conservative window‑scale (6), ECN, and random timestamps as previous releases. mDNS advertising (port 5353/udp) persisted, and OCSP requests identified the user‑agent as com.apple.trustd/3.0, while Safari reported the usual macOS 10_15_7 user‑agent string.
