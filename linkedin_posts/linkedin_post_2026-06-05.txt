Cisco has patched a critical vulnerability, CVE-2026-20230, in Unified Communications Manager and Session Management Edition that allows an unauthenticated attacker to write arbitrary files and escalate to root access. Proof-of-concept exploit code is public, and Cisco has seen no attacks yet, but the risk is high, especially for deployments that have switched on the WebDialer service. Patching is recommended.

2. Claude Code GitHub Action Flaw Let One Malicious Issue Hijack Repositories
Threat: Vulnerability | Severity: 8/10
A security researcher discovered a flaw in Anthropic's Claude Code GitHub Action, allowing an attacker to take over vulnerable public repositories with just a single opened GitHub issue. Anthropic fixed the issue within four days and updated the action to version v1.0.94. Users must update to the latest version and audit their workflows for potential security vulnerabilities to prevent attacks.
