Cybersecurity Intelligence Brief

1. Attacker Used 4,837 Hijacked GitHub Accounts to Run a CI Secret Stealer in 1,806+ Repositories
Threat: Malware | Severity: 9/10
An attacker compromised 4,837 GitHub accounts and used them to inject a secret‑stealing tool into public repositories. The malicious code targeted CI workflows and npm post‑install hooks, affecting at least 1,806 repositories and 8,093 with malicious commits. After brief exposure, changes were reverted and logs deleted. Victims should revoke tokens, enable 2FA, and immediately rotate all exposed secrets and credentials.

2. Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely
Threat: Vulnerability | Severity: 10/10
A critical vulnerability (CVE‑2026‑119618) in Apache HTTP Server’s HTTP/2 module, mod_http2, allows unauthenticated remote code execution on servers with HTTP/2 enabled. It impacts versions 2.4.55‑2.4.70 (and mod_h2 2.0.8‑2.0.42) and is patched in 2.4.71 (released yesterday). Red Hat rates it “Important” for RHEL 9/10 and notes a reliable exploit exists, though no wild attacks have been reported. Administrators should verify HTTP/2 settings and upgrade immediately.

3. ScreenConnect Attacks Target at Least 288 Endpoints Across 48 Organizations With Rogue Clients
Threat: Vulnerability | Severity: 8/10
ConnectWise disabled five third‑party extensions in about 400 partner environments after reports of unauthorized access. The firm says there’s no sign its own infrastructure or ScreenConnect is compromised; the breach likely stems from abuse of the extensions, which require a passphrase. Huntress observed attackers exploiting ScreenConnect panels to run commands and install rogue clients on 288 endpoints across 48 organizations. Investigations continue.

4. Critical Zoom Workplace Flaw Could Allow Unauthenticated Remote Privilege Escalation
Threat: Vulnerability | Severity: 10/10
Zoom has issued patches for two new Windows Workplace vulnerabilities, a critical privilege‑escalation flaw (CVE‑2026‑108187, affecting versions before 7.1.5) and another (CVE‑2026‑108186, affecting 7.1.0‑7.1.8). Earlier in July Zoom also fixed a high‑severity input‑validation bug (CVE‑2026‑53412, CVSS 9.8). No evidence of active exploits, but users are urged to update immediately.

5. AntiFox AI Pentesting Platform Linked to Attacks That Accessed AWS Production Secrets
Threat: Data Breach | Severity: 9/10
Researchers reported that the AI‑driven penetration‑testing platform AntiFox, hosted on Alibaba Cloud and available on GitHub, has been weaponized to steal AWS credentials and move laterally within victim networks. Attackers exploited vulnerable IIS web apps, deployed ASPX web shells via w3wp.exe, then performed recon, credential validation, cloud enumeration, and secret extraction, turning findings into actionable reports.
