Cybersecurity Intelligence Brief

1. Claude Code's “Don't Ask Again” File Exposes Passwords and Keys in 1,122 Public Copies on GitHub
Threat: Data Breach | Severity: 8/10
Anthropic’s Claude Code can store commands—including passwords and API keys—when users select “Yes, and don’t ask again,” saving them in .claude/settings.local.json. Researchers at Apiiro found 1,122 public GitHub repos containing this file with secrets, some still active. The file isn’t automatically git‑ignored, so secrets persist in history and forks. They advise rotating all credentials and cleaning the repo.

2. Installing the Fix for an Exploited WordPress Flaw Can Expose Some Sites One Last Time
Threat: Vulnerability | Severity: 8/10
A WordPress update can be exploited while it installs a fix for CVE‑2026‑119977, affecting versions 4.7‑7.1.3. The updater unpacks new files using the site’s old, vulnerable code, exposing the temporary wp‑content/upgrade folder. An attacker who predicts the folder name can run code, overwrite wp‑config.php, and gain server access. Researchers recommend blocking web access to wp‑content/upgrade during updates. The flaw was added to CISA’s exploited‑vulnerabilities list; WordPress patched it in 7.1.4 (and back‑ports).

3. Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot
Threat: Zero-Day | Severity: 10/10
Threat actors are exploiting a newly disclosed OpenSSH flaw (CVE‑2026‑123158, “SSHole”) that lets unauthenticated attackers log into accounts with no password when OpenSSH runs on musl‑based Linux without PAM (e.g., Alpine Linux). By sending an oversized password (257‑1024 bytes), the hash fails, returns “*”, and matches the account’s disabled‑password marker, granting access. The bug, introduced by a 2016 patch, was fixed in OpenSSH 10.6p2. Within nine hours of disclosure, eight attempts were seen, including a successful root compromise on an Alpine honeypot. The issue does not affect glibc systems, Dropbear, or PAM‑enabled configurations.

4. OpenAI Launches GPT-6 Cyber After AI Helps Find 81 Firefox Flaws, 948 Linux Exploits
Threat: Vulnerability | Severity: 6/10
OpenAI unveiled GPT‑6 Cyber, a “Critical” cybersecurity model that markedly improves vulnerability discovery and alignment. It outperforms GPT‑5.6 Cyber and GPT‑6 Astra, staying within task boundaries 99.93% of the time (100% with safety prompts) and scoring 48.5% on the ExploitGym benchmark versus 32.1% previously. The model auto‑found 948 Linux privilege‑escalation bugs, 81 new high‑severity Firefox flaws and a critical Brotli issue, and is now available via API to select Daybreak Red customers with added misuse‑prevention guardrails.

5. Microsoft Paint RCE Fix Now Available, but Windows Update Won't Deliver It
Threat: Vulnerability | Severity: 9/10
Microsoft has released a fix for the critical Paint RCE bug (CVE‑2026‑83844) via a Microsoft Store update, not through regular Windows patches. The remedial build is 11.2609.401.0, which the Store now offers in ten countries; older builds (e.g., 11.2605.81.0) remain unpatched. The flaw is an out‑of‑bounds read allowing remote code execution, rated Important with an 8.1 CVSS. Deployment speed varies, and the advisory’s fixed‑build range was recently updated without clear notice.
