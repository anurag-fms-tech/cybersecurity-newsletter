1. GitHub Cuts Public Bug Bounty Payouts, Moves Top Rewards to VIP Tier
Threat: Vulnerability | Severity: 3

This news involves a change in the payout structure for a security bug bounty program, which could potentially affect the motivation of researchers to report vulnerabilities. However, it does not directly indicate a specific vulnerability or risk to users./10
GitHub will cut public bug bounty payouts by at least half starting July 27, 2026. Critical findings will drop from $20,000-$30,000+ to a fixed $10,000. Established researchers may qualify for a VIP tier offering higher rewards. Fixed payments aim to reduce uncertainty and triage, with discretionary bonuses for exceptional work.

2. Ubuntu snap-confine Flaw Could Give Local Users Root on Default Desktop Installs
Threat: Vulnerability | Severity: 9/10
Cybersecurity researchers have disclosed a new high-severity vulnerability (CVE-2026-8933, CVSS score: 7.8) in snap-confine that allows unprivileged users to gain root access. This affects default Ubuntu Desktop installations (24.04, 25.10, 26.04) and is caused by a race condition in sandbox initialization. Attackers can manipulate file permissions, allowing root code execution and a complete environment takeover.

3. Adobe Acrobat Extension Flaw Let Malicious Sites Read WhatsApp Web Data
Threat: Vulnerability | Severity: 9/10
A vulnerability, codenamed HermeticReader (CVE-2026-48294), existed in Adobe Acrobat Chrome extension with over 314 million users. It allowed attackers to silently hijack a user's WhatsApp data through user interaction, no malware or credentials required. The flaw was patched but not before researchers demonstrated its potential to access session-bound data, including WhatsApp content.

4. Hackers Exploit Windmill Flaw to Read Arbitrary Server Files Without Authentication
Threat: Vulnerability | Severity: 8/10
A high-severity security flaw in Windmill's "get_log_file" endpoint has been exploited in the wild, allowing attackers to read arbitrary files or execute code as a superadmin. The issue, CVE-2026-29059 (CVSS 7.5), was fixed in Windmill 1.603.3. VulnCheck has detected 170 vulnerable systems across 24 countries, with exploits also targeting a Nextcloud proxy path.
