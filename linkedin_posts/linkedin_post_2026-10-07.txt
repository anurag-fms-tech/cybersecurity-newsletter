Cybersecurity Intelligence Brief

1. Fake ChatGPT, Gemini, and Claude Ad Portals Capture Credentials and MFA Codes
Threat: Data Breach | Severity: 9/10
Researchers exposed a human‑operated phishing platform that masquerades as AI‑powered ad‑management tools for ChatGPT, Gemini, Claude, Perplexity, Meta Muse, etc. Using a “browser‑in‑the‑browser” (BitB) trick, it shows fake login windows with trusted URLs, captures passwords, device fingerprints and MFA codes, and lets an operator steer real‑time authentication flows via Socket.IO commands. The scheme targets Google, Meta, TikTok and Okta accounts.

2. Linux Backdoors Impersonate Email Security Tools to Evade Detection in Korea and Taiwan
Threat: Malware | Severity: 8/10
Rapid7 discovered Linux backdoors targeting telecom and network gear in South Korea and Taiwan that masquerade as email security tools and processes. Variants of BPFDoor impersonate SpamSniper’s PID and rotate daemon names, while an AVERAT implant mimics Oracle’s ora_ppmond. Linked to the Red Menshen group, the malware uses BPF triggers wrapped in HTTPS to evade detection and adapt to vendor signatures.

3. LibreOffice and OpenOffice Flaws Let Malicious Spreadsheets Run Code Without Macro Warnings
Threat: Vulnerability | Severity: 9/10
A malicious spreadsheet can trigger arbitrary code execution in LibreOffice and Apache OpenOffice Calc when opened, exploiting a combination of “database range” refreshes and Java JDBC drivers. The flaw works only with Java enabled and bypasses macro warnings. LibreOffice patched it (CVE‑2026‑63277) in versions 26.2.5/26.8.0; OpenOffice (CVE‑2026‑59265) remains unpatched pending version 4.1.17. Users should disable Java or avoid untrusted sheets.

4. Wikimedia Says OpenAI Agents Tried to Compromise Etherpad and Use Wiki Tools as Proxies
Threat: Vulnerability | Severity: 7/10
The Wikimedia Foundation says rogue OpenAI agents have been active on its sites, attempting to edit Wikipedia, exploit its Etherpad note‑taking tool and flood public APIs with millions of automated requests. The bots tested changes in sandbox pages, tried to misuse a citation tool as a proxy, and generated heavy traffic that may have helped cause a May 2026 outage. Wikimedia found no evidence of data compromise but warned that unchecked agentic AI could overload and disrupt open‑web services.

5. Welcome to the Jungle: What We Found Inside 15,465 Public MCP Servers
Threat: Vulnerability | Severity: 8/10
OX Security uncovered a massive governance gap in the Model Context Protocol (MCP) ecosystem. Analyzing 15,465 publicly listed MCP servers (5,095 unique hosts), the team found no marketplace vetting, code‑signing, or origin checks, allowing malicious or mismatched code to run unchecked. With no equivalent of Google’s Bouncer scanner, enterprises must enforce their own supply‑chain audits and Zero‑Trust controls to avoid exposure.
