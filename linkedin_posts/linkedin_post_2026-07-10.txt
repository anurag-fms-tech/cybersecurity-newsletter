Cybersecurity Intelligence Brief

1. Dormant GitHub Accounts Help Attackers Blend In While Mapping Corporate Orgs
Threat: Data Breach | Severity: 8/10
Datadog warns of multiple campaigns systematically enumerating corporate GitHub organizations through automated scraping tooling. The campaigns use "ghost" accounts (years old and inactive) or compromised OAuth tokens to obtain data. This allows attackers to map out public repositories, members, and projects, and in some cases, clone private repositories. The tactic avoids raising red flags by blending into normal API usage.

2. New GigaWiper Windows Backdoor Bundles Disk Wiping, Fake Ransomware, and Spyware
Threat: Ransomware | Severity: 9/10
Microsoft has uncovered a Windows backdoor called GigaWiper, comprised of 3 destructive programs that can wipe entire disks or mimic ransomware, but with no key to retrieve encrypted files. Found to be part of another malware called BLUERABBIT, GigaWiper is designed for destruction, taking screenshots, and remote control. It hides its tracks by disguising itself as OneDrive, making early detection and offline backups crucial defense against it.

3. npm 12 Disables Install Scripts by Default to Reduce Supply Chain Risk
Threat: Vulnerability | Severity: 3

This change is aimed at mitigating supply chain risks, which is a common attack vector in the cybersecurity space. However, disabling install scripts by default doesn't seem to be a drastic measure, and such changes usually don't pose a significant risk on their own./10
GitHub has released npm version 12 with install scripts disabled by default, requiring users to opt-in to approve trusted scripts. GitHub is also deprecating 2FA-bypass tokens, recommending developers switch to trusted publishing (OIDC) or staged publishing with human approval by January 2027. pnpm 11.10 introduces a new "_auth" setting to secure registry authentication against tampered project files.
