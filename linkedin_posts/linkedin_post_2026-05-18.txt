Cybersecurity Intelligence Brief

1. NGINX CVE-2026-42945 Exploited in the Wild, Causing Worker Crashes and Possible RCE
Threat: Vulnerability | Severity: 8/10
A newly disclosed security flaw (CVE-2026-42945) in NGINX versions 0.6.27-1.30.0 has been exploited in the wild. The vulnerability, a heap buffer overflow, allows an attacker to crash worker processes or execute remote code with crafted HTTP requests. However, execution requires a specific NGINX config and ASLR to be disabled. Threat actors have started to exploit the flaw, prompting users to apply the latest fixes from F5 to secure their networks.

2. Grafana GitHub Token Breach Led to Codebase Download and Extortion Attempt
Threat: Data Breach | Severity: 8/10
Grafana disclosed a breach where an unauthorized party accessed its GitHub environment using a compromised token, but no customer data was accessed. The company thwarted the attacker's attempt to blackmail and extort them, aligning with FBI advice. The breach has not been attributed to a known group, although the "CoinbaseCartel" is suspected and was identified as a data extortion group targeting multiple industries.

3. Funnel Builder Flaw Under Active Exploitation Enables WooCommerce Checkout Skimming
Threat: Vulnerability | Severity: 8/10
A critical security vulnerability in the Funnel Builder plugin for WordPress has been exploited to inject malicious JavaScript code into WooCommerce checkout pages, stealing payment data. The flaw affects all versions before 3.15.0.3, used in over 40,000 stores. Site owners must update the plugin and review external scripts to prevent potential credit card theft.

4. Turla Turns Kazuar Backdoor Into Modular P2P Botnet for Persistent Access
Threat: Malware | Severity: 9/10
Russian state-sponsored hacking group Turla has transformed its backdoor tool Kazuar into a modular peer-to-peer (P2P) botnet, designed for stealth and persistent access. Kazuar now consists of three component types, including Kernel, Bridge, and Worker modules, enabling flexible configuration, reducing observability, and facilitating tasking for intelligence collection.

5. Four OpenClaw Flaws Enable Data Theft, Privilege Escalation, and Persistence
Threat: Vulnerability | Severity: 8/10
Cybersecurity firm Cyera discovered four vulnerabilities, dubbed "Claw Chain," in OpenClaw that can be chained to achieve data theft, privilege escalation, and persistence. The flaws, addressed in OpenClaw version 2026.4.22, allow attackers to establish a foothold, expose sensitive data, and plant backdoors, making detection difficult due to resembling normal agent behavior.
