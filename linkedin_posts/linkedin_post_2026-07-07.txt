1. Iran-Linked Hackers Use New Cavern C2 Framework to Target Israeli Organizations
Threat: Nation State | Severity: 8/10
An Iranian hacking group linked to the country's intelligence ministry has developed a modular command-and-control framework called Cavern, targeting Israeli organizations, particularly IT and government sectors. The framework's mature design makes it adaptable and difficult to analyze, using uncommon .NET compilation formats to reduce forensic visibility and ensure persistent access.

2. 16-Year-Old Linux KVM Flaw Lets Guest VMs Escape to Host on Intel and AMD x86 Systems
Threat: Vulnerability | Severity: 9/10
A 16-year-old "use-after-free" bug in Linux's KVM hypervisor, dubbed "Januscape", allows a virtual machine to corrupt the host's kernel, potentially leading to full host code execution. Researcher Hyunwoo Kim discovered the flaw, which can crash the host or, in a rarer scenario, grant limited control. The bug affects both Intel and AMD chips, and a proof-of-concept demonstration has been released.

3. Threat Actors Probe Gitea Docker Flaw CVE-2026-20896 13 Days After Disclosure
Threat: Vulnerability | Severity: 8

This rating is based on the fact that 13 days have passed since the vulnerability was disclosed, which is considered a relatively short time for a malicious actor to take action./10
Threat actors are trying to exploit a critical vulnerability (CVE-2026-20896) in Gitea Docker images, allowing unauthenticated users to gain elevated access. The flaw was patched in version 1.26.3, but attackers were detected 13 days after public disclosure, attempting to exploit the vulnerability in about 6,200 internet-facing Gitea instances.
