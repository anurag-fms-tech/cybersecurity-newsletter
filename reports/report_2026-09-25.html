Unpatched OnePlus Flaws Let Installed Android Apps Gain Root Without Permissions

Threat: Vulnerability
Severity: 9/10

One URL, Three Different Tricks, (Thu, Sep 24th)

Threat: Malware
Severity: 7/10

A new phishing URL exploits parsing discrepancies by embedding a random “userinfo” string before an “@”, making each link unique and appearing like an email address. The hostname “gynd--.koncar-hr.com” violates strict RFC rules (hyphens at start/end), causing some validators to reject it while browsers still resolve it. The path appends the victim’s email, enabling auto‑fill and misleading parsers into thinking the link points to a trusted domain. Detect such URLs by spotting multiple “@” signs, hyphen‑edge host labels, or paths containing the recipient’s address.
