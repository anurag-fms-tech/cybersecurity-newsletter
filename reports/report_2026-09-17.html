Parallels Desktop Flaw Lets Non-Admin Mac Users Gain Root, but Intel Macs Can't Install Fix

Threat: Vulnerability
Severity: 9/10

Parallels Desktop for Mac contains a local privilege‑escalation flaw dubbed “ParaShells” (CVE‑2026‑90894) that lets any non‑admin user run code as root. The vulnerability stems from a world‑writable socket used by the background prl_disp_service, which accepts unvalidated commands that are passed to tar running as root, allowing arbitrary programs to execute with full system privileges. JFrog disclosed the issue, rated it 7.8/10, and confirmed a fix in Parallels Desktop 27—though Intel‑based Macs cannot install that version. The exploit works locally without network access and affects the host Mac, not the VMs.
