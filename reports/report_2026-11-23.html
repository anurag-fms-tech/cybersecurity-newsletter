Researchers Demonstrate Ghostscript Sandbox-Escape RCE via Crafted File Uploads in Popular Apps

Threat: Vulnerability
Severity: 9/10

A use‑after‑free bug in Ghostscript (CVE‑2026‑125396) let a crafted PDF/PostScript/EPS file bypass the -dSAFER sandbox and execute commands on the server processing it. pwn.ai showed the flaw could be triggered through ordinary upload, preview or print features in about ten popular apps—ImageMagick, Pillow, libvips, WordPress plugins, Roundcube, etc.—often without direct calls to Ghostscript. The bug, fixed in Ghostscript 10.08.0 on Sept 8, scores 8.5/10; no attacks have been reported. Updating both Ghostscript and affected applications (e.g., WordPress 7.0.4) is required.

A brief history of syslog timestamps, (Sun, Nov 22nd)

Threat: Vulnerability
Severity: 1/10

Debian 12 and Ubuntu 23.04 dropped the `RSYSLOG_TraditionalFileFormat` directive from rsyslog’s default config, causing logs to switch from the classic “Mmm dd hh:mm:ss” BSD format to ISO‑8601/RFC‑3339 timestamps. While most distros still default to the systemd journal, admins who keep rsyslog notice the change. Fedora, AlmaLinux and other Red Hat‑based releases retain the legacy format.
