Threat: Vulnerability
Severity: 9/10

PHP’s default file‑based session handler had a critical flaw (CVE‑2026‑126714, “phpAfterShell”) that lets an attacker interrupt a session write, inject arbitrary objects, and—if a suitable gadget chain exists—execute code on the server. The bug, discovered by Depthfirst, is patched in today’s PHP releases (including 8.6.0) but remains in older builds and in versions that used the earlier “PHP2Shell” fixes.
