Threat: Vulnerability
Severity: 10/10

A critical flaw (CVE‑2026‑105192) affects LMCache’s multiprocess mode used by LLM servers like vLLM. An attacker can send a crafted ZeroMQ message that’s unpickled, executing code as the LMCache process (root). The bug spans v0.3.9 through v0.5.5 and rc 0.5.6, with no patch yet.
