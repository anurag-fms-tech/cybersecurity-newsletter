OpenSSL HollowByte Flaw Could Freeze Server Memory with 11-Byte TLS Requests

Threat: Vulnerability
Severity: 9/10

A vulnerability in OpenSSL's TLS handshake has been revealed, allowing attackers to exhaust system memory by causing a denial-of-service (DoS) with unpatched servers. The "HollowByte" flaw allows an attacker to claim an excessively large message size, causing the server to allocate memory but then drop the connection, freezing fragments of memory that can persist until the process restarts.
