HTTP QUERY Method: The Grey Zone Between GET And POST., (Fri, Sep 18th)

Threat: Vulnerability
Severity: 2/10

In June 2026 the IETF released RFC 10008, introducing “QUERY”—the first new HTTP verb since PATCH. It behaves like a GET with a body, is safe, idempotent and cache‑able, and servers announce accepted body formats via an “Accept‑Query” header. Existing security controls (WAFs, API gateways, CSRF middleware, caches) were built around a fixed verb set, so many reject, ignore, or mishandle QUERY, creating inspection bypasses and cache‑poisoning risks until they’re updated.
